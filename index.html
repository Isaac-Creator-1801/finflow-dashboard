Sincronização em Nuvem

📌 Como funciona: configure um banco Supabase gratuito e os dados serão salvos automaticamente na nuvem. Você e a Rodrega acessam e editam tudo em tempo real de qualquer dispositivo!

Use o mesmo ID nos dois dispositivos para compartilhar os dados.
📋 Passo a passo Supabase:
1. Acesse supabase.com e crie uma conta grátis
2. Crie um novo projeto
3. No SQL Editor, execute: CREATE TABLE finflow_state (id text PRIMARY KEY, data jsonb, metas jsonb, dividas jsonb, updated_at timestamptz);
4. Copie a URL e API Key das Configurações do projeto
